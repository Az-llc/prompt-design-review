# transcript-failure-scan

手元にある Claude Code の会話の記録から、繰り返し起きている失敗を数え、その数を Claude に分析させて、直し方の案を選べる形で出す Claude Code のプラグインです。

[English README](README.md)

## 概要

数えるのはスクリプトで、分析するのは Claude です。

- スクリプトは、Claude Code の設定フォルダにある会話の記録をすべて読み、止められたツール呼び出しと失敗したツール呼び出しを、同じものごとにまとめます。対象は hook による停止、権限の拒否、コマンドの失敗、ツールのエラー、遅い呼び出しです。まとまりごとに、件数、会話の数、日付、同じ呼び出しをやり直した回数、立て直すまでにかかった呼び出しの数を出します。
- 設定についての事実も並べます。hook の登録とそのスクリプトがあるかどうか、hook の matcher に書かれているのに記録に一度も出てこないツール名、記録に出てくる Claude Code の版、hook のスクリプト・rule・CLAUDE.md が加わった時期です。
- Claude は、まとまりごとに元の記録を開き、原因がどこにあるか（あなたの設定、リポジトリのコード、Claude Code 自体）を決めて、直し方を提案します。提案するのは仕組みです（hook、設定、スクリプトの変更）。あなたが選ぶまで、何も変更しません。

原因のありかを分けることに意味があります。Claude Code 自体が原因の失敗は、CLAUDE.md に決まりを足しても直りません。また、決まりが書いてあるのに同じ失敗が続いていることも、数で分かります。

## 限界

- 数えられるのは、残っている記録だけです。Claude Code は、`cleanupPeriodDays`（既定は 30 日）より長く更新されていない会話の記録ファイルを消します。設定を変えていなければ、数はおよそ直近 1 か月分です。
- 何も止めずに通した hook は、記録に残りません。そのため分析は、「記録に停止が無い」ことを hook を外す理由にしません。外す提案をするのは、ファイルが無いことの確かめ、実際に試した結果、公式の文書との食い違いのどれかがあるときだけです。
- 分析は、一覧の項目ごとに記録を 1 件以上開きます。項目が多いほど費用が増えます。スキルは数え終えた後に項目の数を伝え、全部を分析するか一部だけにするかをたずねます。
- 出力フォルダには、手元のすべてのプロジェクトの会話の抜粋が入ります。スキルはこれをシステムの一時フォルダの下に作り、分析が終わったとあなたが伝えた時に消します。

## インストール

```text
/plugin marketplace add Az-llc/prompt-design-review
/plugin install transcript-failure-scan@az-llc
```

このプラグインは版 0.10 で、更新はしません。公開した時点の形のまま置いてあり、中の走査の道具も公開時のままです。LAISORA の側の道具は変わり続けるので、後で両者に違いが出ることがあります。

## 使い方

```text
/transcript-failure-scan:scan
```

新しい会話で実行してください。このスキルは、このコマンドを入力したときだけ動きます。Claude が自分の判断で始めることはありません。

新しい会話で実行する理由は、次に数えるときの扱いにあります。分析をした会話は、次回の集計から会話ごと外れます。ほかの作業の途中で実行すると、その作業の記録も一緒に外れるか、逆に分析の会話が集計に混ざります。

Claude は所見を出したところで止まり、あなたが選ぶまで何も変更しないよう指示されています。これは指示であって、ツールを使えなくする仕組みではありません。

## 前提

- Claude Code
- Node.js 20 以降

スクリプトは通信しません。手元のファイルを読み、指示ファイルの日付を調べるために `git log` を実行し、出力フォルダにだけ書き込みます。

## スクリプトの出どころ

`skills/scan/scripts/improvement.mjs` は、同じ作者の VS Code 拡張 [LAISORA](https://github.com/Az-llc/LAISORA) が使っている走査の道具を、公開時点のものそのまま入れたものです。LAISORA は走査をメニューから実行します。LAISORA が入っていれば、スクリプトはそれを見つけて、LAISORA 自身が止めた件をそう表示します。止めたときの文面がどの hook のスクリプトにも見つからなかった停止は、止めた場面とツール名、そこに登録されている hook の候補と一緒に並びます。どちらでも、前に行った分析の会話は次に数えるときに対象から外れ、全部を分析したときの判定は次回、同じまとまりの横に表示されます。範囲を絞った分析の判定は、次回へ引き継ぎません。
